# 品牌视觉资产

登录页潮汐画与品牌 Logo 的图片放这里(`public/` 下的文件按 `/brand/xxx` 直接访问,
不经过打包,替换文件即可生效,无需改代码)。**资产缺失时组件会退回中性灰占位,不会破图。**

## 现有资产

| 文件 | 尺寸 | 用途 |
| --- | --- | --- |
| `logo.png` | 1254×1254(透明底) | 顶部导航左侧(26px)、登录表单上方(44px)、首页理念条右侧(40px) |
| `tide-back.png` | 2172×724(透明底) | 潮汐画远景层,漂移 20s / 轮 |
| `tide-mid.png` | 2172×724(透明底) | 潮汐画中景层,漂移 14s / 轮 |
| `tide-front.png` | 2172×724(透明底) | 潮汐画近景层,漂移 8s / 轮 |

三层由远及近速度递增,形成视差。**素材不需要左右边缘可对接**:代码把每层排成
「原图 / 镜像 / 原图」三份,镜像保证接缝两侧像素一致,所以循环处不会跳变。
(一轮位移 = 两份 = 2 屏宽,故时长是「每屏 10/7/4 秒」的 2 倍。三份是最少够用的
数量,少一份画面会不够铺、多一份纯属浪费显存。)

## 可选资产

- `logo-light.png` —— 深色底上用的浅色版标志(组件里 `variant="light"` 会用它)。
- 若要把 Logo 换成 favicon:替换 `public/favicon.svg`(或用 `logo.png` 生成同名 `.svg`/`.ico`)。

## 微调位置与大小

潮汐画的分层参数都在 `src/index.css`,不用改组件:

- `--tide-scale`:整幅潮汐画的缩放(默认 `1`;觉得太小就调大,如 `1.3`)。
- `--tide-offset`:单层上下位置微调(如给 `.tide-layer--back` 加 `--tide-offset: 8%` 让它更靠上)。
- 速度即各层 `animation-duration`(数值越小越快)。

图层高度由 `.tide-layer` 的 `aspect-ratio: 9 / 1` 决定(层宽 = 3 屏 ⇒ 层高 = 一屏宽/3),
这样图层只覆盖波浪那一条,不留大片透明区。**换成不是 3:1 的图时要同步改这个比值**:
`aspect-ratio` 填 `3 × 画幅宽高比`,例如 4:1 的图填 `12 / 1`。

## 设计规格(重新生成时参考)

- **Logo**:方形画布、图形居中、四周留 ~8% 安全边距;**不含文字**(文字由代码排 `producthub`);
  扁平简洁、2 色以内、无渐变噪点与投影;缩到 24px 仍清晰可辨;透明底。
- **潮汐画**:横向长幅、透明底、画面左右可无缝重复;**不含文字**
  (「每一次起落,皆为蓄力」由代码排版);避免大面积纯黑/纯白,以免与叠加文字打架。
